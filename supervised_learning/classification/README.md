# Classification: Neural Networks from Scratch

This repository contains a structured progression of machine learning models for binary and multiclass image classification. Designed as a hands-on exploration of artificial intelligence concepts, the project builds up from a single logistic regression neuron to a fully dynamic deep neural network.

As part of ongoing work within the Artificial Intelligence department at Kyungdong University, this project emphasizes the mathematical and theoretical foundations behind machine learning frameworks.

## Core Concepts

- **Network Architecture:** Progressing from a single node to hidden layers and deep network structures.
- **Propagation & Optimization:** Implementing forward propagation, computation graphs, backpropagation, and gradient descent.
- **Activation Functions:** Utilizing Sigmoid, Tanh, ReLU, and Softmax to optimize training.
- **Data Handling:** One-hot encoding, dataset splitting, and model persistence.

## Repository Structure

- **0 to 7-neuron:** Implementation of a single neuron performing binary classification, including evaluation, gradient descent, and training loops.
- **8 to 15-neural_network:** A foundational network featuring exactly one hidden layer.
- **16 to 23-deep_neural_network:** A dynamic deep network supporting multiple hidden layers and He initialization.
- **24-one_hot_encode & 25-one_hot_decode:** Utilities for matrix transformations.
- **26-deep_neural_network:** Adding model persistence to save and load training states.
- **27 & 28-deep_neural_network:** Advanced upgrades for multiclass classification and configurable activation functions to maximize accuracy and minimize cost.
